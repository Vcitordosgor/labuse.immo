Demander une démo

Vous vous demandez peut-être…

Comment se passe la démo ?+

Vous avez accès à tout LABUSE pendant 48 h : la carte, les outils, le Copilote, les documents. Sans engagement.

Les données sont-elles à jour ?+

Oui, c’est notre engagement : vous travaillez sur la dernière donnée en date. Sur la fiche, les données affichent leur source.

LABUSE dit-il si un terrain est constructible ?+

Il vous dit ce que permet la zone du PLU (constructible, à urbaniser, agricole ou naturelle), avec les risques et les contraintes connues : vous savez vite si le terrain mérite d’aller plus loin. Pour une réponse qui engage, c’est le certificat d’urbanisme de la mairie.

Voit-on qui possède un terrain ?+

Oui, quand le propriétaire est une personne morale (société, collectivité, association…). Un particulier n’est jamais nommé.

Puis-je utiliser LABUSE sur mon téléphone ?+

L’app s’utilise sur ordinateur : la carte a besoin de place. Le rapport Flash, lui, est un PDF qui se lit partout.
